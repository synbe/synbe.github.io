# wavemessenger
一款基于声波技术的跨设备文本传输工具，无需网络、无需数据线、无需搭建服务器，仅通过声音即可实现手机与电脑之间的文本/代码/文档片段传输，纯静态前端实现，适配全平台浏览器，开箱即用。

## ✨ 核心特性
- **无网无线传输**：依托声波编码技术，摆脱网络、数据线、蓝牙依赖，5米内无遮挡环境稳定传输
- **纯静态零配置**：无需搭建HTTP服务器，直接本地打开HTML文件即可运行，无任何后端依赖
- **跨平台兼容**：支持Windows/macOS/Android/iOS，任意现代浏览器（Chrome/Edge/Safari等）均可运行
- **长文本分片传输**：自动将长文本按30字符/片切割（避免解码乱码），接收端自动拼接合并
- **轻量化交互**：仿Telegram聊天式界面，操作简单，支持消息复制、下载、日志自动保存
- **隐私安全**：所有数据仅在设备间本地处理，无云端存储，无第三方服务器中转
- **简洁UI设计**：深色主题适配，响应式布局，兼顾手机/电脑端操作体验

```bash
# 电脑端：双击 index.html 文件，用任意现代浏览器打开即可
# 手机端：将仓库文件拷贝至手机本地，用手机浏览器打开 index.html 文件
```

### 2. 基础使用教程
#### 传输准备
- 确保发送/接收设备的扬声器、麦克风正常工作，并给浏览器授予麦克风权限
- 设备间距控制在5米内，尽量在安静环境下使用（减少噪音干扰解码）
- 手机端访问本地文件：将仓库文件夹通过微信/QQ/数据线拷贝至手机，用浏览器打开 index.html 即可

#### 文本传输步骤
1. **接收方**：点击页面右上角「监听」按钮，状态栏显示「监听中」（红色脉冲圆点）
2. **发送方**：在输入框输入/粘贴文本（支持长文本自动分片），点击「发送」按钮
3. **接收方**：自动解码并显示接收内容，长文本会按片段展示（标注分片序号）
4. **合并查看**：长文本全部接收完成后，可查看合并后的完整内容，支持一键复制/下载
5. **日志保存**：点击「保存日志: 关」可开启自动保存，所有传输记录会以文本文件形式留存

## 🛠 技术实现
### 核心依赖
- 声波编码/解码：基于 [ggwave](https://github.com/ggerganov/ggwave) 音频数传库实现
- 前端技术：原生HTML/CSS/JavaScript，无框架依赖，纯静态实现
- 音频处理：Web Audio API（采样率48000Hz）实现音频采集/播放
- 界面设计：自定义CSS变量实现Telegram风格深色主题，响应式布局适配多设备

### 核心逻辑
- **分片传输**：长文本按30字符/片拆分（避免解码乱码），内置10秒超时机制确保分片完整接收
- **音频参数**：采样率48000Hz，声音标记阈值4，平衡传输稳定性与抗干扰能力
- **交互设计**：聊天式消息展示，支持分片序号标注、合并内容预览、一键复制/下载

## 📋 功能细节
### 核心操作按钮
| 按钮         | 功能说明                                  |
|--------------|-------------------------------------------|
| 监听         | 开启/关闭麦克风监听，接收声波传输的文本    |
| 保存日志     | 切换是否自动保存传输记录（按时间戳生成文件）|
| 粘贴         | 快速粘贴剪贴板内容至输入框                |
| 发送         | 将输入框文本编码为声波发送                |
| 复制（消息） | 复制单条消息/合并后完整文本至剪贴板       |
| 下载（消息） | 将文本保存为本地.txt文件                  |

### 分片传输规则
- 单片段最大字符数：30（经测试该长度解码稳定性最优）
- 分片超时时间：10秒（超时未接收则停止等待该批次分片）
- 消息展示：分片消息标注「X/Y」序号，合并后标注「已合并Y片段」

## 📋 适配场景
- 户外办公：断网环境下电脑→手机传输代码/文档片段
- 会议室：无共享网络时，快速分享会议纪要至参会者手机
- 应急场景：无数据线/U盘时，手机/电脑互传验证码、登录信息
- 隐私传输：无需第三方平台，数据仅在设备间本地流转

## ⚠️ 注意事项
1. 声波传输受环境噪音影响较大，嘈杂环境建议缩短设备间距或切换至安静区域
2. 部分浏览器（如Safari）对麦克风权限要求严格，需手动授权；优先推荐使用Chrome/Edge
3. 纯静态运行模式下，部分浏览器可能限制本地文件读取，直接双击 index.html 可规避该问题
4. 传输超长篇文本时，建议开启「保存日志」避免内容丢失
5. 若出现解码失败，可检查设备音量/麦克风权限，或重新开启监听模式
